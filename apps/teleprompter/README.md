# 念白 · 提词器

一个可离线使用的中文提词器网页应用。稿件和偏好设置都保存在当前浏览器的本地存储中。

## 打开

直接在浏览器中打开 `index.html`。若浏览器限制本地文件存储，在该目录运行 `python3 -m http.server 8000`，再访问 `http://localhost:8000`。

## 功能

- 创建、编辑、重命名和自动保存多份稿件
- 导入 Word（`.docx`）、Markdown（`.md` / `.markdown`）及 UTF-8 TXT 文件；导出为 TXT
- 调节字号和滚动速度，设置 3、5 或 10 秒倒计时
- 开始、暂停、拖动进度，启用镜像翻转
- 进入全屏提词，使用空格和方向键控制播放

稿件保存在当前设备的浏览器中；清理浏览器站点数据会删除本地稿件。

Word 文件需为现代 `.docx` 格式，旧版二进制 `.doc` 暂不支持。Markdown 导入会移除标题、列表、链接和强调标记，保留正文内容与段落。

`.docx` 解压使用本地打包的 fflate 0.8.2，MIT 许可见 `vendor/LICENSE-fflate.txt`；运行时不需要联网加载解析库。
