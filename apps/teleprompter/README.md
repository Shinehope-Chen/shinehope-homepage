# 念白 · 提词器

一个可离线使用的中文提词器网页应用。稿件和偏好设置都保存在当前浏览器的本地存储中。

## 打开

直接在浏览器中打开 `index.html`。若浏览器限制本地文件存储，在该目录运行 `python3 -m http.server 8000`，再访问 `http://localhost:8000`。

## 功能

- 创建、编辑、重命名和自动保存多份稿件
- 导入 Word（`.docx`）、Markdown（`.md` / `.markdown`）及 UTF-8 TXT 文件；导出为 TXT
- 调节字号、1–240 像素/秒滚动速度、行距、左右留白与字体颜色，设置 3、5、10 或 15 秒倒计时
- 开始、暂停、拖动进度，启用镜像翻转
- 进入专注提词，在桌面端和手机端直接暂停或调整速度、字号
- 启用口播跟随：将中文语音识别结果与稿件定位匹配，并按实际朗读节奏校准常规滚动速度
- 使用画中画悬浮提词，在支持画中画的视频浏览器中切换到其他 App 后继续查看稿件
- 调用前置或后置摄像头录制，实时把提词文字合成到视频中，并保存或通过系统分享
- 使用空格和方向键控制播放与速度，使用 `+` / `-` 调整字号；支持浏览器屏幕常亮锁时，在播放期间阻止屏幕休眠
- 针对 iPhone Safari 调整动态可视高度与安全区；扩大触控区域，编辑输入不会触发页面自动放大，专注模式始终可退出

稿件保存在当前设备的浏览器中；清理浏览器站点数据会删除本地稿件。

Word 文件需为现代 `.docx` 格式，旧版二进制 `.doc` 暂不支持。Markdown 导入会移除标题、列表、链接和强调标记，保留正文内容与段落。

口播跟随依赖浏览器的 Web Speech 语音识别接口和麦克风权限；不同系统、语言及网络环境的支持情况不同，语音识别是否由设备本地完成取决于浏览器实现。画中画取决于浏览器是否允许网页视频进入画中画，iPhone Safari 的普通标签页支持情况优于主屏幕网页应用。摄像录制需要 HTTPS（或本机 `localhost`）以及相机和麦克风权限；录制期间暂时关闭口播跟随，以避免争用麦克风。请在目标手机的 Safari 中确认这几项系统能力与权限后再正式拍摄。

`.docx` 解压使用本地打包的 fflate 0.8.2，MIT 许可见 `vendor/LICENSE-fflate.txt`；运行时不需要联网加载解析库。
